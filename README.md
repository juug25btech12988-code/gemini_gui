# A custom Tkinter based Desktop App for interacting with gemini
This was created with Tkinter and customtkinter.
It uses google.generativeai(deprecated) to communicate with gemini.
It supports text input and output only.
offers the following models:
Gemini 1.5 Flash
Gemini 1.5 Flash 8B
Gemini 1.5 Pro 
Gemini 2.0 Flash 
Gemini 2.0 Flash Lite 
Gemini 2.5 Flash
Gemini 2.5 Flash Preview 04-17
Gemini 2.5 Pro
Gemini 2.5 Flash Lite Preview 06 17
